# 💰 Smart Budget Tracker

### Personal Finance Management System with a Free Budget Assistant

Smart Budget Tracker is a Python-based personal finance management web application developed using **Streamlit**. It helps users manage their income, track expenses, set monthly budgets, monitor savings goals, and understand their financial habits through an interactive dashboard.

The application features a modern **purple-themed interface**, local database storage, financial reports, and a free rule-based Budget Assistant that provides personalized insights based on recorded financial data.

## 🚀 Features

### 📊 1. Interactive Dashboard
- View total income, expenses, and available balance.
- Monitor monthly financial performance.
- Visualize spending patterns using interactive charts.
- Track monthly budget usage.
- Receive notifications when spending approaches or exceeds the budget.

### 💵 2. Income and Expense Management
- Add income and expense transactions.
- Organize transactions into categories.
- Record transaction dates and descriptions.
- Edit or delete existing transactions.
- Maintain a detailed financial transaction history.

### 🎯 3. Budget Management
- Set monthly spending budgets.
- Compare actual spending against the monthly budget.
- Monitor remaining budget amounts.
- Receive alerts when spending reaches 80% of the budget.
- Identify when monthly expenses exceed the allocated budget.

### 🏦 4. Savings Goals
- Create personal savings goals.
- Set target savings amounts.
- Record current savings progress.
- Assign target deadlines.
- Monitor progress toward financial goals.

### 📅 5. Monthly Financial Reports
- Review income and expenses for selected months.
- Analyze monthly financial performance.
- Track spending by category.
- Compare income and expenses.
- Export monthly transaction reports.

### 🤖 6. Free Rule-Based Budget Assistant

The application includes a built-in financial assistant that helps users understand their financial information.

**Assistant Capabilities:**
- Answer questions about monthly expenses.
- Display the current financial balance.
- Provide monthly budget status.
- Identify top spending categories.
- Show savings goal information.
- Offer general savings suggestions.
